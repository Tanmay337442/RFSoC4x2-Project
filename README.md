# RFSoC4x2-Project

This repository contains a custom RFSoC 4x2 overlay, Jupyter notebooks, custom IP, constraints, and generated hardware files. The Jupyter notebooks include explanations of their configuration parameters, functions, and execution steps. Documentation is maintained in the lab's Outline workspace. The archived Vivado 2025.2 project for the final FPGA overlay is available under [Releases](https://github.com/Tanmay337442/RFSoC4x2-Project/releases/tag/v1.0.0).
